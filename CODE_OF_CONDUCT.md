# Code of conduct

We want a friendly, useful place for people who build and run machines.

- Be respectful. Criticise ideas and code, not people.
- Assume good faith, and ask when something is unclear.
- Welcome beginners and non-native English speakers (German and English are both fine in issues).
- Keep safety discussions factual: say what you saw, what you tested, and on which hardware.
- No harassment, discrimination, personal attacks, or publishing other people's private data.

The maintainer may edit, hide or remove comments and contributions that break these rules, and may block repeat offenders. To raise a concern, contact the maintainer through GitHub (private message or a security advisory if it is sensitive).
